# Cross-agent review gate
- [ ] Owner-approved issue scope & dependencies, no unrelated churn.
- [ ] Domain validation and transaction boundary correct; institution/event isolation and stale revision enforced.
- [ ] No hidden relaxation, partial publish, fabricated state, false success, float currency, duplicate honor or unsafe delete.
- [ ] Typed bridge and safe file operations; no secrets/real student data; offline operation.
- [ ] UI tokens, nav/breadcrumb, table/actions, centered modal, all states, dark/light, keyboard, DPI.
- [ ] Test commands executed, actual output inspected, native results distinguished from web mock; migration/restore evidence if relevant.
- [ ] Changes documented, issue acceptance checked, risk and rollback notes, owner approval before merge.
